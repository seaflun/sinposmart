# Project Skills

This folder keeps project-local skill guidance for the SinpoSmart duty automation project.

## Included Skills

- `superpowers`: vendored Superpowers workflow skills for planning, debugging, TDD, branch finishing, code review, and verification.

## Usage

Before using these skills in Codex, ensure they are also installed locally under `%USERPROFILE%\.codex\skills` or otherwise available through the active Codex skill roots.

Do not put secrets, tokens, passwords, `.env` files, logs, or runtime output in this folder.
