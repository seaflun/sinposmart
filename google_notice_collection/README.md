# 電子通報收取 Apps Script

`apps-script/` 保存已部署第 9 版的完整來源，與 2026-10-22 正式下載的來源逐檔相同。這裡不保存 `.clasp.json`、OAuth 憑證或本機驗收工具；GUI 更新包也不需要包含這個目錄。

## 自動建立月份檔

- 母檔整份複製，保留 33 個分頁、公式、格式與下拉規則。
- 目的地固定為「電子通報收文／民國年度／民國年月份電子通報」。年度資料夾不存在時在既定主資料夾下建立。
- 只有真正寫入通報、取得 ScriptLock 後才能建立。`checkExisting` 不建立資料夾或月份檔。
- 既有月檔沿用；不採用其他位置的同名檔或舊 ID 快取。同名年度或月檔不唯一時停止並回報。
- 刪除空白測試月檔後，未來首次寫入該月份的新通報仍會重新複製母檔。母檔、主資料夾與部署者的 Drive／Sheets 授權必須保留。

## 測試與部署

執行 `node --test google_notice_collection/tests/monthly-workbook.test.js`，不需額外 Node 套件。19 項測試涵蓋查詢不建檔、跨年位置、既有月份沿用、錯誤快取、同名歧義、型別與失敗重試，以及鎖內建立。

2026-10-22 以 sinpo666@gmail.com 實測建立 115 年 11 月與 116 年 1 月，確認唯一年度位置、相同檔案 ID 重查、各 33 分頁與 3,416 條公式、主要格式、93 個人員下拉規則及日期運算。僅用空白格暫測公式，完成後清空；沒有建立測試通報列，母檔未修改。

後續部署須另有使用者授權，以 sinpo666@gmail.com 更新既有 deployment 並維持 GUI 使用的網址。第一次使用新增 Drive 功能時須確認已授權，不能只用唯讀查詢成功判斷複製權限。不要將暫時驗收入口加入正式部署。
