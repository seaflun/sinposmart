# SinpoSmart 值班 GUI 定時清理設計

## 目的

值班 GUI 通常長時間持續執行，不能再只依賴程式啟動時清理資料。新增每天 03:00 的清理排程，並讓「每日勤務表」與「夜間勤務」PNG 截圖只保留 30 天。

## 範圍

- 保留現有 JSON 清理期限：
  - `runtime_outputs/schedule/*.json`：45 天。
  - `runtime_outputs/comparison/*.json`：45 天。
  - `runtime_outputs/rehearsal/*.json`：14 天。
  - `runtime_outputs/form_tests/*.json`：7 天。
  - `runtime_outputs/snapshots/*.json`：14 天。
- 新增 PNG 清理期限：
  - `每日勤務表/*.png`：30 天。
  - `夜間勤務/*.png`：30 天。
- 不處理子資料夾、其他副檔名、車輛作業截圖、表單測試 PNG、問題回報包或 NAS 後台資料。

## 執行時機

1. GUI 啟動時先執行一次清理，延續現有行為。
2. GUI 計算下一個本機時間 03:00，使用 Tkinter `after` 安排回呼。
3. 03:00 回呼執行 JSON 與勤務表 PNG 清理。
4. 每次清理結束後重新計算下一個 03:00，避免長期運行時只執行一次。
5. 若電腦休眠或 GUI 事件迴圈延遲，回呼恢復後執行，再安排下一個 03:00。

## 刪除判斷

- 依檔案最後修改時間判斷。
- 檔案年齡嚴格超過保留天數才刪除。
- 只刪除符合指定資料夾及副檔名的檔案。
- 單一檔案無法讀取或刪除時略過，不中斷 GUI，也不影響其他檔案。
- 不刪除資料夾。

## 截圖覆蓋行為

勤務表截圖維持現有「月日」檔名，例如 `0722.png`。同一勤務日期重新登打並成功匯出時，覆蓋原本的每日勤務表與夜間勤務圖片，不建立帶流水號的新檔。

## 程式設計

- 修改既有 `WinPython_公務電腦使用包/duty_gui.py`，不新增 Python 檔案。
- 抽出可重用的依期限清理函式，供現有 JSON 規則與新增 PNG 規則使用。
- 在既有 `DutyGui` 類別加入安排下一次 03:00 清理及執行清理的方法。
- 保留現有啟動流程、錯誤略過策略與相對路徑行為，不改動登入、勤務登打或截圖產生邏輯。

## 測試

- 在既有測試檔加入暫存資料夾測試，不使用正式截圖：
  - 超過 30 天的 PNG 會刪除。
  - 未滿 30 天的 PNG 會保留。
  - 同資料夾內的非 PNG 檔案會保留。
  - JSON 既有 7／14／45 天規則不變。
  - 排程會指向下一個本機時間 03:00。
- 執行相關單元測試、完整 smoke tests、Python 編譯檢查及 `git diff --check`。

## 非目標

- 不變更勤務表截圖檔名或覆蓋規則。
- 不立即清理 NAS、Google Drive 或公務電腦以外的位置。
- 不新增設定畫面、第三方 dependency、背景執行緒或 Windows 工作排程。
