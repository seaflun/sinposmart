# 每日工具自動執行

## 已確認規則

- 值班模式每日 09:00 執行每日點車；16:25 執行下一消防日的勤務表。
- 登入且當日勤務表查詢已驗證人員後才能啟動。快取番號不算完成驗證。
- 前景及背景登打的執行中、已排入佇列工作均會延後啟動；尚未到時間的未來工作不阻擋。
- GUI 未開或尚未登入時，於啟動、登入驗證後補跑。每日點車午夜後不補跑；勤務表補跑至下一日 08:00。
- 手動成功完成相同目標日期後，不再自動執行。兩項逾時工作依 09:00、16:25 順序各自執行。
- 每工具、每消防日最多一次自動嘗試；執行前原子保存 claim，重新啟動不重送未知結果。失敗不無限重試。
- 不新增 GUI 自動登打文字、倒數或確認視窗。沿用既有工具結果；期限與紀錄異常只寫後台事件。

## 勤務表來源

優先沿用既有 last_selection.workbook_path，不新增路徑設定。必須驗證目標年月、日分頁及必要欄位。
若前次檔案不適用，從其路徑推導原根目錄，再查找目標民國年份與月份，例如 115/9月。
只在目標目錄找含新坡及勤務表的 .xlsm，排除 Excel 暫存、備份、舊版及副本。多份有效檔案使用檔案系統最近修改時間；同時刻不猜測，改人工確認。
檔案在背景讀取，不執行巨集；準備完畢再次檢查登入與工作佇列。來源在選取後變動則停止。
只有登打成功才更新前次檔案。選檔候選與修改時間保存在 runtime_outputs/daily_workbook_selection.json。
